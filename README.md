# Act2GIT_AdrianW

Actividad 2 de Git y GitHub del módulo Despliegue de Aplicaciones Web (DAW).

## Descripción

Página web sencilla con cabecera, menú de navegación y footer. Se usa para practicar el trabajo con Git: commits, etiquetas, ramas, fusiones, forks y pull requests.

## Estructura del proyecto

- `index.html`: página de inicio.
- `styles.css`: hoja de estilos.
- `horario.html`: página con el horario de clase (rama `desarrollo`).
- `sobre-mi.html`: página con datos personales (rama `feature1`).

## Ramas

- `main`: rama principal.
- `desarrollo`: nuevas páginas y mejoras.
- `feature1`: página "Sobre mí".

## Versiones

V1.0, V2.0 y V3.0.

## Cómo verlo

Descarga el repositorio y abre `index.html` en el navegador.
